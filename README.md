# حاسبة أرباح المتجر الإلكتروني (Next.js + Tailwind)

موقع ثابت (static export) يُستضاف مجاناً. لا يحتاج سيرفر ولا قاعدة بيانات.

## طريقة الفتح
**لتشوف الموقع بدون برمجة:** فك ضغط `tajer-calc-site.zip` وافتح `index.html` بالضغط عليه مرتين، أو من Live Server. يشتغل من أي مجلد.

**للتطوير:**
```bash
npm install
cp .env.example .env.local   # عبّئ الاسم والدومين والإيميل
npm run dev                  # http://localhost:3000 (أماكن الإعلانات تظهر كمربعات منقطة هنا فقط)
npm test                     # يقارن الحساب بالنسخة الأصلية على 600 حالة عشوائية
npm run build                # يُخرج الموقع الجاهز في مجلد out/
```
لا تفتح ملفات `.tsx` في المتصفح، فهي كود المصدر وليست صفحات. الصفحات الجاهزة تُنتج داخل `out/` بعد `npm run build`.

### لماذا `next build --webpack`؟
بعد البناء يحوّل `scripts/relative-paths.mjs` كل المسارات إلى نسبية، فيشتغل الموقع من ملف مباشر أو مجلد فرعي أو GitHub Pages
بدون دومين. محرك Turbopack (الافتراضي) يتعرّف على ملفاته بالمسار الحرفي، فيتوقف React بصمت مع المسارات النسبية،
لذلك البناء يستخدم webpack. لا تحذف `--webpack` من `package.json`.

## الهيكل
- `lib/calc.ts` كل الحسابات، دالة واحدة بدون React. أي تعديل على المعادلات هنا فقط، وشغّل `npm test` بعده.
- **نسبة التأكيد (الدفع عند الاستلام):** تكلفة الإعلان "لكل طلب" أو من تكلفة النقرة تُقسم على نسبة التأكيد، لأن الطلبات غير المؤكدة لا تُشحن لكن إعلانها مدفوع. الميزانية الشهرية لا تُقسم لأنها مقسومة أصلاً على الطلبات المشحونة. 100% (الافتراضي) يعطي نفس نتائج النسخة الأصلية.
- **"بكم أبيع؟":** `priceForTarget` في `lib/calc.ts`. الربح خطّي في السعر، فالسعر لأي هدف (هامش أو ربح ثابت) له حل دقيق، وأعلى هامش ممكن هو ميل الخط.
- **رابط المشاركة وتذكّر الأرقام:** `lib/state.ts`. الرابط يحمل فقط القيم المختلفة عن الافتراضية، وكل ما يُقرأ من رابط أو من ذاكرة المتصفح يُتحقق منه قبل استخدامه.
- **صورة المعاينة:** `public/og.png` مولّدة من `scripts/og-card.html`. لو غيّرت التصميم أو الاسم، صوّرها من جديد بمقاس 1200×630. ورابطها يعتمد على `NEXT_PUBLIC_SITE_URL`، فلازم تضبطه قبل البناء.
- `components/Calculator.tsx` الواجهة (useState + useMemo): الإيصال، والشريط الثابت على الجوال.
- `components/charts/SensitivityChart.tsx` الرسم "متى يبدأ الطلب بالخسارة؟" (SVG بدون مكتبات): تلميح يتبع المؤشر، أسهم لوحة المفاتيح، وجدول.
- `components/charts/BreakdownBar.tsx` شريط توزيع السعر داخل الإيصال، لكل جزء تلميح.
- `components/ui/Toast.tsx` الإشعارات (مع "تراجع")، و`components/ui/InfoTip.tsx` تلميحات "؟".
- `components/ThemeToggle.tsx` الوضع الليلي (تلقائي، فاتح، داكن)، يُحفظ في المتصفح ويُطبَّق قبل ظهور الصفحة.
- `lib/motion.ts` حركة الأرقام وتلميع القيم المتغيّرة. كل الحركات تتوقف عند تفعيل "تقليل الحركة" في الجهاز.
- ألوان الرسم في `app/globals.css` (`--c1`..`--c7`) مفحوصة لعمى الألوان في الوضعين. لو غيّرتها، افحصها من جديد.
- `components/PrintReport.tsx` تقرير الطباعة. يُعرض تحت `<body>` مباشرة عبر portal.
- `components/AdSlot.tsx` مكان الإعلان. لا يظهر شيء في الإنتاج قبل وضع معرّف AdSense.
- `app/*/page.tsx` الصفحات مع metadata لكل صفحة. `app/sitemap.ts` و`app/robots.ts` يتولّدان تلقائياً.
- `tests/fixtures/prototype.html` النسخة الأصلية، مرجع اختبار الحساب. لا تحذفه.

## قبل النشر (مطلوب منك)
1. `.env.local`: الاسم والدومين والإيميل.
2. `app/about/page.tsx`: استبدل `[اسمك أو اسم الفريق]` والنبذة بمعلومات حقيقية.
3. `app/privacy/page.tsx`: استبدل `[تاريخ آخر تحديث]`.
4. راجع رسوم سلة وأسعار الباقات (آخر مراجعة 1 أكتوبر 2026).

## النشر على GitHub Pages
ارفع المشروع إلى مستودع، ثم Settings > Pages > Source = GitHub Actions، وضع قيم `NEXT_PUBLIC_*` في
Settings > Secrets and variables > Actions > Variables. الملف `.github/workflows/deploy.yml` يبني وينشر مع كل push.

## AdSense
قدّم بالموقع بدون إعلانات. بعد القبول: ضع `NEXT_PUBLIC_ADSENSE_CLIENT` ومعرّفات الوحدات، وأعد تسمية
`public/ads.txt.example` إلى `ads.txt` بمعرّفك. أماكن الإعلانات: بعد الحاسبة، ووسط كل دليل. لا تضع إعلاناً بجانب الخانات أو الأزرار.
